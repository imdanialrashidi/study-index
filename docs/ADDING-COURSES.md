# افزودن دوره جدید

افزودن یک دوره یعنی ساختن **یک فایل** در `src/content/courses/`. نیازی به
تغییر هیچ کامپوننت یا صفحه‌ای نیست؛ فهرست، بخش ویژه و صفحات جزئیات به‌طور
خودکار از همین فایل‌ها ساخته می‌شوند.

## قدم‌ها

۱. فایل نمونه را کپی کنید و به نام اسلاگ دوره تغییر نام بدهید:

```bash
cp src/content/courses/example-course.md src/content/courses/my-course.md
```

نام فایل همان اسلاگ است: فقط حروف کوچک انگلیسی، عدد و خط تیره
(مثل `discrete-math`). صفحه جزئیات در `/courses/my-course/` ساخته می‌شود.

۲. فیلدهای جلوی فایل (frontmatter) را پر کنید — همه مقادیر باید واقعی و
تاییدشده باشند:

```yaml
---
title: "نام دوره"              # الزامی، ۳ تا ۸۰ نویسه
description: "توضیح کوتاه…"     # الزامی، ۲۰ تا ۲۲۰ نویسه
subject: "ریاضی"                # الزامی، دسته‌بندی (مثل ریاضی، فیزیک، زبان)
website: "https://…"            # الزامی، نشانی وب‌سایت دوره (فقط https)
status: "published"             # draft = پنهان، published = عمومی
github: "https://…"             # اختیاری، مخزن گیت‌هاب
cover: "../../assets/covers/x.png"  # اختیاری، تصویر محلی داخل src/assets
coverAlt: "توصیف فارسی جلد"     # توصیه‌شده وقتی cover هست
tags: ["برچسب یک", "برچسب دو"]  # اختیاری، حداکثر ۸ برچسب
featured: true                  # اختیاری، نمایش در بخش «دوره‌های ویژه»
order: 1                        # اختیاری، ترتیب نمایش (کمتر = بالاتر)
stats:                          # اختیاری، فقط عددهای تاییدشده
  - value: "۱۲"
    label: "فصل آموزشی"
---
```

۳. متن آزاد زیر frontmatter در **صفحه جزئیات** دوره نمایش داده می‌شود:
سرفصل‌ها، پیش‌نیازها و نحوه استفاده از وب‌سایت دوره را آنجا بنویسید.

۴. تصویر جلد (اختیاری): فایل را در `src/assets/covers/` بگذارید و در فیلد
`cover` به آن ارجاع بدهید. اگر جلد نباشد، یک بلوک تایپوگرافیک خودکار
نمایش داده می‌شود — هیچ‌وقت تصویر خراب نمایش داده نمی‌شود.

## پیش‌نمایش و اعتبارسنجی

```bash
npm run dev      # پیش‌نمایش زنده در http://localhost:4321
npm run build    # اعتبارسنجی کامل + خروجی استاتیک در dist/
```

`npm run build` همه ورودی‌ها را با اسکیمای `src/content.config.ts` بررسی
می‌کند. ورودی نامعتبر با خطای مشخص و نام فایل، بیلد را متوقف می‌کند؛
مثلاً نشانی بدون `https://` یا فیلد `status` خارج از `draft`/`published`.

## انتشار و پنهان‌سازی

- انتشار: `status: "published"` → دوره در فهرست، بخش ویژه (اگر
  `featured: true`) و صفحه جزئیات ظاهر می‌شود.
- پیش‌نویس: `status: "draft"` → فقط اعتبارسنجی می‌شود، هیچ‌جا نمایش داده
  نمی‌شود. فایل `example-course.md` همیشه `draft` می‌ماند تا اسکیما را
  تمرین بدهد بدون اینکه داده نمونه در سایت عمومی دیده شود.

## قوانین داده (مهم)

- فقط دوره‌های `published` عمومی می‌شوند — استثنایی وجود ندارد.
- هیچ عدد، آمار یا ادعای تکمیلیِ تاییدنشده ننویسید (تعداد دانشجو، درصد
  رضایت و…). فیلد `stats` فقط برای رقم‌هایی است که روی وب‌سایت زنده دوره
  قابل شمارش‌اند.
- پیوندها باید واقعی و سالم باشند؛ `website` حتماً با `https://` شروع شود.
- متن‌ها فارسی طبیعی و بدون اغراق تبلیغاتی باشند.
